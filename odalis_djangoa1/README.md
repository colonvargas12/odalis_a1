# odalis portafolio

Proyecto Django de marca personal.

## Apps del proyecto

- `mi_marca`: contiene la landing page principal.
- `principal`: app secundaria del proyecto.

## Ejecutar

```bash
pip install -r requirements.txt
python manage.py runserver
```

Abrir:

```text
http://127.0.0.1:8000/
```

App secundaria:

```text
http://127.0.0.1:8000/principal/
```
